# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in this project, please report it
responsibly. Do not open a public GitHub issue for security vulnerabilities.

Report security issues to [security@databricks.com](mailto:security@databricks.com)
and include a description, reproduction steps, and the potential impact.

## Supported versions

Security fixes are applied to the `main` branch and the latest published
release, if any.
