==============================================================================
Databricks SQL Kernel Release Notes
==============================================================================

The release notes summarize enhancements, new features, known issues, and
version history for the Databricks SQL Kernel (OSS) and its Python and
Node.js bindings.

Version History ==============================================================

0.1.2 ========================================================================
Released 2026-06-06

Initial public release.

Enhancements & New Features

 * Rust core kernel published to crates.io as `databricks-sql-kernel`.
 * Python bindings published to PyPI as `databricks-sql-kernel` — abi3
   wheels for Linux (manylinux_2_28 x86_64/aarch64), macOS (x86_64/arm64),
   and Windows (x86_64), plus a source distribution.
 * Node.js (napi) bindings published to npm as
   `@databricks/databricks-sql-kernel` — an umbrella loader package plus
   per-platform native packages for Linux gnu/musl (x64/arm64), macOS
   (x64/arm64), and Windows (x64/arm64).
