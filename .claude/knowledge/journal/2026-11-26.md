# Learning journal 2026-11-26

### 2026-11-26: Arrow results and metadata — Apply metadata shape fixes to both native and SHOW-fallback paths
**Context:** PR #506 kept null/empty TABLE_TYPE rows in the SHOW TABLES fallback reshape. A reviewer found that native GetTables results go through normalize_native_metadata_batch and process_native_tables, which skipped the new helper. Native empty types were still dropped by a ["TABLE"] filter, and a native null failed schema reconstruction with DataLoss because the public TABLE_TYPE field is non-nullable.
**Rule:** When changing how a metadata column is normalized or filtered, apply the change and its tests to both the native (x-databricks-require-thrift-native-metadata) path and the SHOW fallback path, and default nulls before rebuilding into a non-nullable public schema.

### 2026-11-26: Arrow results and metadata — GetTables type filters let unknown table types through
**Context:** PR #506 matched legacy Thrift GetTables and JDBC: rows from legacy hive_metastore whose TABLE_TYPE is null or empty are emitted as "" and kept even when a non-empty table_types filter is supplied. An explicit empty filter still matches nothing, and "TABLE" is used only when the tableType column is missing entirely.
**Rule:** In table_types filtering, keep rows whose TABLE_TYPE is null or empty (emit them as ""), exact-match only known types, and return no rows for an explicit empty filter.

### 2026-11-26: Verification and CI — Keep safety caveats and option references when trimming docs
**Context:** PR #503 cut the ADBC README down. Reviewers flagged several omissions: the warning that the TLS self-signed and hostname-verification bypasses are unsafe, the note that the C driver reports cancellation as NotImplemented, and every auth/config option key. The keys are private consts, so the README was their only public reference.
**Rule:** When condensing user docs, keep security warnings, per-surface limitations (for example, features only available from native Rust), and a reference for option keys, or link to a doc that has them.
